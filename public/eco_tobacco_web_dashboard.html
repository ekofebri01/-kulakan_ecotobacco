Panduan Lengkap: Cara Edit dari Laptop & Masuk ke HP

1
Edit Data di Laptop

Buka tab Kelola Transaksi di web ini. Tambah transaksi baru, perbaiki nota yang salah, atau ubah harga tembakau sesukamu.

2
Simpan ke Cloud

Tekan tombol hijau "Unggah Semua ke Cloud" (atau tombol Sinkron Cloud di kanan atas). Data langsung tersimpan di server.

3
Tarik Masuk di HP

Di HP Android kamu, buka ECO TOBACCO > Pengaturan > tekan "Pulihkan Cloud Langsung". Semua transaksi yang kamu edit di laptop seketika muncul di HP!
